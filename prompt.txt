
file sturcture:
dataset/

    sentences.txt: Preprocessed sentences extracted from the dataset. (one sentence per line)
    embeddings.pkl: Serialized embeddings of sentences.
    labels.npy: Cluster labels for each sentence.
    clusters.json: Mapping of cluster IDs to sentences

note:
    1. sentence in the sentences.txt has its embedding in embeddings.pkl at the same index

important:

File Structure for cluster.json:

The JSON object is a dictionary:
    Keys: Cluster IDs (as strings)
    Values: Lists of sentence objects belonging to that cluster

Data Format:
    Each cluster contains multiple entries with the following structure:

    id (int): Unique identifier of the sentence (index in the dataset)
    sentence (string): The actual text content of the sentence

Example

{
    "113": [
        {
            "id": 0,
            "sentence": "A renewed push for 'Buy America' could complicate matters..."
        },
        {
            "id": 16,
            "sentence": "Heightened geopolitical tensions also weighed on investor sentiment."
        }
    ]
}
